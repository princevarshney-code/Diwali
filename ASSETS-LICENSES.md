## Audio: NOT INCLUDED
No recorded audio is in this package. I could not reach any sound library from my build environment (only GitHub and package registries were reachable), and the firework audio I found on GitHub was either music tracks or had no stated licence, so I did not copy it. I have not verified any specific clip, so none is named here as approved.

Missing files, expected in `assets/audio/`:
1. `fireworks-crackling.mp3` – recorded firecrackers crackling and bursting
2. `distant-fireworks.mp3` – distant fireworks popping at night
3. `diya-bell.mp3` – optional soft bell or chime (played when a diya is lit and when the greeting opens)

Where to look (check each clip's own licence page before using it):
- Freesound.org: filter by the **Creative Commons 0** licence. CC-BY clips need credit added to this file.
- Pixabay Sound Effects: covered by the Pixabay Content License; read its current terms.
- Your own recordings.

Keep clips short (2–10 s), trimmed, and exported as MP3 around 96–128 kbps. After adding a file, record its title, author, source URL and licence in a table here.
